BayCopier

Site access

BayCopier needs access to eBay to read sold listings and fill in the listing form.

eBay API keys optional

From your eBay developer keyset (Production). With keys set, BayCopier asks eBay's Browse API for the description and photos first. eBay's API only returns listings that are still live, so sold listings are read from the page either way.

Keys are stored only in this Firefox profile and sent only to api.ebay.com.
