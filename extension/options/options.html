Download

After downloading, open about:debugging#/runtime/this-firefox, click Load Temporary Add-on… and pick the downloaded .zip. It replaces this version — don't click Remove first.

eBay API keys

Optional

From your eBay developer keyset (Production). With keys set, BayCopier asks eBay's Browse API first. That API only returns listings that are still live, so sold listings are read from the page either way.

Keys are stored only in this Firefox profile and sent only to api.ebay.com.
